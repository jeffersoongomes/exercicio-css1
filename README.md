# 🎨 Exercício Prático: Developer Profile Card

Este repositório contém um exercício prático de **CSS3** focado na construção de um card de perfil responsivo e moderno para desenvolvedores.

## 🚀 Conceitos Praticados

- **Box Model:** Manipulação de `margin`, `padding`, `border`, `border-radius` e dimensões customizadas.
- **Flexbox:** Centralização da estrutura na tela (`justify-content`, `align-items`) e organização interna dos elementos (tags de habilidades e layout vertical).
- **Posicionamento CSS:** Uso de `position: relative` e `position: absolute` para posicionar o selo de status `ONLINE` sobre o card.
- **Reset CSS:** Normalização de margens e aplicação do `box-sizing: border-box`.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
